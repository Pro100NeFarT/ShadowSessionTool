# Засіб тіньових сеансів (ShadowSessionTool)

Невеликий адміністративний застосунок для Windows Server (RDP/RDS) — перегляд активних сеансів, тіньове підключення без згоди користувача, керування сеансами та розсилка повідомлень. Заміна ручного набору команд `query session` / `mstsc /shadow`.

![.NET Framework 4](https://img.shields.io/badge/.NET%20Framework-4.0-blue) ![Windows](https://img.shields.io/badge/Windows-Server%202012%20R2%20--%202022-0078D6)

## Можливості

- **Список сеансів** — користувач, ID, стан, ім'я сеансу, кількість запущених процесів 1С/BAS, опис облікового запису (з локальних користувачів Windows — зазвичай ПІБ співробітника); отримується через нативний WTS API (не через парсинг тексту консолі), тому коректно працює незалежно від мови ОС (українська/російська/англійська)
- **Пошук** одночасно за іменем користувача й описом облікового запису в реальному часі, **сортування** по кліку на будь-який заголовок колонки
- **Тіньове підключення** (`Підключитися`) — перегляд і керування чужим сеансом; якщо групова політика без згоди не ввімкнена, автоматично підключається зі звичайним запитом дозволу користувача замість помилки
- **Перейняти сеанс (за паролем)** — аналог команди «Подключить» у Диспетчері завдань Windows: повністю замінює ваш поточний сеанс сеансом іншого користувача (через `tscon.exe`), а не просто переглядає його
- **Перевірка та увімкнення групової політики** тіньового підключення без згоди користувача (`Set rules for remote control...`) — зелений/червоний індикатор і кнопка одним кліком
- **Завершення сеансів** — одного, кількох вибраних (Ctrl/Shift), або всіх відключених одразу
- **1С/BAS**: лічильник активних процесів (`1cv8`/`1cv8c`) по кожному сеансу; окремо — завершити ці процеси, або комбінована дія «Очистити кеш 1С/BAS» (завершує процеси → чистить кеш конкретного користувача, не чіпаючи інформаційні бази й налаштування торгового обладнання → надсилає повідомлення «Можна працювати»)
- **Надсилання повідомлень** вибраним сеансам або всім одразу (крім власного), із шаблонами (закриття 1С/BAS, дозвіл на роботу, попередження про перезавантаження)
- **Планове перезавантаження сервера** — через N хвилин або на конкретну годину, з автоматичною розсилкою попередження всім активним сеансам і можливістю скасувати
- **Контекстне меню (ПКМ)** — усі дії з тією ж логікою доступності, що й кнопки, з коректною поведінкою виділення (як у Провіднику)
- **Інформація про IP сервера** — локальні адреси всіх мережевих адаптерів і зовнішня (публічна) адреса, кожна копіюється в буфер обміну окремим кліком
- **Три теми оформлення** — світла, темна (типова), синя; вибір запам'ятовується між запусками
- **Автооновлення** — тиха фонова перевірка при запуску; якщо є новіша версія, номер версії у вікні підсвічується (без нав'язливого спливаючого вікна), клік по ньому — оновлення одним підтвердженням

## Вимоги

- Перевірено на Windows Server 2012 R2, 2016, 2019 та 2022; має працювати на Windows 10/11
- Права адміністратора (застосунок запитує підвищення прав автоматично при запуску)
- Інтернет-доступ — для автооновлення й визначення зовнішнього IP; без нього застосунок повністю функціональний, просто без цих двох речей

## Встановлення

1. Завантажте `ShadowSessionTool.exe` з [Releases](../../releases) або напряму з кореня репозиторію
2. Запустіть — Windows запитає підтвердження підвищення прав (UAC)

Встановлення не потрібне: один файл, без залежностей окрім .NET Framework 4 (вже вбудований у Windows Server 2012 R2+ та Windows 10+).

## Збірка з вихідного коду

Проєкт — один файл `ShadowSessionTool.cs`, компілюється вбудованим у Windows компілятором `csc.exe` (з .NET Framework), без потреби встановлювати .NET SDK чи Visual Studio:

```powershell
$csc = "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe"
& $csc /target:winexe /platform:anycpu `
    /out:ShadowSessionTool.exe `
    /win32manifest:app.manifest `
    /win32icon:ShadowSessionTool.ico `
    /reference:System.dll,System.Windows.Forms.dll,System.Drawing.dll `
    ShadowSessionTool.cs
```

Іконку (`ShadowSessionTool.ico`) можна перегенерувати скриптом `GenerateIcon.ps1`.

## Автооновлення — як це працює

При кожному запуску застосунок тихо звіряє власну версію з файлом [`version.txt`](version.txt) у цьому репозиторії (`raw.githubusercontent.com`, HTTPS, без токена). Якщо версія новіша — номер версії у верхньому лівому куті вікна стає помаранчевим (`v1.4.0 ↑`), без спливаючого вікна. Клік по ньому одразу пропонує оновитися; якщо клікнути, коли оновлень не знайдено — застосунок перевірить ще раз і повідомить результат (найновіша версія / помилка мережі).

Після згоди на оновлення застосунок завантажує новий `.exe`, примусово закриває всі запущені копії процесу (щоб уникнути блокування файлу) та підміняє його.

Щоб випустити нову версію: підняти номер у `version.txt` і закомітити оновлений `ShadowSessionTool.exe` в гілку `main`.

## Примітки щодо безпеки

- Тіньове підключення без згоди користувача — це навмисна адміністративна функція (стандартна можливість RDS), яка вимагає відповідної групової політики; використовуйте лише на серверах, якими адмініструєте
- «Перейняти сеанс» передає пароль користувача `tscon.exe` як параметр командного рядка — це документований спосіб Microsoft, але пароль теоретично на мить видимий іншим процесам з достатніми правами на тому ж сервері (обмеження самого `tscon`, не застосунку)
- «Очистити кеш 1С/BAS» видаляє лише конкретні службові підтеки (`Config`, `ConfigSave`, `DBNameCache`, `SICache`, `vrs-cache`) у профілі користувача за припущенням стандартного шляху `C:\Users\<ім'я>\...` — якщо на сервері нестандартні шляхи профілів (роумінг-профілі, редиректи), очищення може не спрацювати
- Визначення зовнішнього IP звертається до стороннього сервісу `api.ipify.org` по HTTPS (лише щоб отримати адресу, більше жодних даних не передається)
- Застосунок не збирає й не передає жодних інших даних, окрім перевірки версії при оновленні
